All commits in this project must be authored as `prince-panwar`. Before committing, set the local repo identity:

```
git config user.name "prince-panwar"
git config user.email "<prince-panwar@users.noreply.github.com or the real address>"
```

Or pass `--author="prince-panwar <email>"` per commit. Do not commit from any other identity, and do not change this without explicit instruction.
